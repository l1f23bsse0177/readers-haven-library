# Readers' Haven Public Library

A responsive static website for Readers' Haven Public Library, developed as part of the DevOps Fundamentals course assignment.

## Project Overview

The website provides information about the library's collections, membership plans, services, and contact details.

## Technologies Used

- HTML5
- CSS3
- Parcel (Build Tool)
- Docker
- Nginx

## Website Pages

1. Home
2. Collections
3. Membership
4. Services
5. Contact

## Team

Developed by a team of six students as part of the DevOps Fundamentals assignment.
